sitalOS Music Storage
====================

Place your custom MP3 songs in this folder.
When deployed to cPanel, this maps to public_html/music/

Default Track Filenames:
- track1.mp3 (Default: Lofi Study Beats)
- track2.mp3 (Default: Cyber City Lights)
- track3.mp3 (Default: Midnight Stroll)
- track4.mp3 (Default: Solar Wind)
- track5.mp3 (Default: Tokyo Neon)

Optional Cover Art Filenames:
- cover1.jpg
- cover2.jpg
- cover3.jpg
- cover4.jpg
- cover5.jpg

If any track file is not present, sitalOS automatically falls back to online streaming without breaking the player.
